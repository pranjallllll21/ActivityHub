# Event Management Module

> **Phase 2** — To be implemented

This module will handle:
- **Event Creation** — Committee members create events tied to their club
- **Event Approval Workflow** — HOD reviews and approves/rejects events
- **Event Browsing** — Students can browse upcoming approved events
- **Event Registration** — Students register for events (with capacity limits)

## Planned Files
- `events.controller.ts` — Route handlers
- `events.service.ts` — Business logic
- `events.validation.ts` — Zod schemas for request validation
- `events.routes.ts` — Express router
