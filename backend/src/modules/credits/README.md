# Credit Allocation Module

> **Phase 5** — To be implemented

This module will handle:
- **Automatic Credit Allocation** — Award AICTE points when attendance is marked or certificates approved
- **Credit Calculation** — Apply formula: AICTE Points = Hours / 4
- **Credit Dashboard** — Students view their accumulated credits
- **Credit Reports** — Faculty/HOD view credits by student, department, or category
